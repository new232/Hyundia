작업이 끝날 때마다 세 가지를 합니다.

1. 테스트 · uv·Poetry는 앞에 uv run·poetry run을 붙입니다.

2. 바뀐 파일 확인 · Copilot은 소스 제어 창(Ctrl+Shift+G, Mac은 Cmd+Shift+G). 바뀌면 안 되는 파일(tests/, SPEC 파일, static/)이 보이면 AI에게 “마지막 커밋 상태로 되돌려 줘”라고 부탁합니다.

agy에 입력 · 바뀐 내용

3. 커밋 · AGENTS.md 규칙대로 AI가 보고 끝에 커밋 메시지를 제안합니다. 테스트 결과·바뀐 파일·메시지를 읽고 맞으면 “승인”이라고만 씁니다.

에이전트에 입력 · 메시지가 없을 때

성공 기준 · 결과를 읽고 “승인”을 썼습니다.

결과물은 “승인” 전에 다음으로 넘어가지 않습니다.

review-thermo 밖에 새 폴더 review-cleanbot을 만들고 docs/04-cleanbot-request.md를 REQUEST.md로 복사합니다. 가상환경·pytest 설치 후 agy를 켭니다. 세션 4와 같은 순서이고, “승인” 뒤에 저장합니다.

agy에 입력 · 인터뷰
/grill-me REQUEST.md를 읽고 이 프로젝트의 AGENTS.md를 만들려고 해. 프로젝트 소개, 기준 문서, 만드는 파일, 실행 방법, 고치면 안 되는 파일, 일하는 방법, 끝났을 때 보고할 것을 정해야 해. 하나씩 물어봐 줘. 질문은 7개까지. 다 물어본 뒤 초안을 보여 주고, 내가 "승인"이라고 하면 저장해.

Copilot: 채팅에 /grill-me가 안 보이면 grill-me 스킬대로 해 줘라고 씁니다.

표를 먼저 봅니다. 안 되면 손을 듭니다. 네트워크가 막히면 강사에게 알립니다.
